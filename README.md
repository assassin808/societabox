# YAX

Foundation repository for YAX (products: SocietaBox, a trainable generative social sandbox; SocietaGene, the cognitive genome): a running record of ideas, decisions, and progress.

## Layout

- `LOG.md`: chronological journal, newest entries at the top. Every update, idea dump, or decision gets a dated entry.
- `DECISIONS.md`: key decisions and the reasoning behind them.
- `notes/`: longer topic notes (market, product, customers, team, finances) once there is enough material.
