认知基因组沙盒

一个会生长的社会沙盒：用认知基因组模拟真实的人，用强化学习学出世界本身，让模拟人群像真人，也让在里面训练的 agent 学会真实的社会能力。

Haoyang Shang（UBC）· Xuan Liu（UC San Diego）交互式 demo：SocietaBox Town
一句话主张模拟人群最难的不是平均值，而是人与人的差异，以及人如何随情境改变。我们把人拆成可测、可调的认知基因，把世界做成可以生长的脚本图，再用强化学习同时学会两件事：这个人此刻会怎么做，以及世界下一步该出什么题。

1问题

  • 合成人群平均对、差异错。它们能复现平均答案，却答得过于一致、压缩量表、扭曲特质间关系，对条件变化的反应也失真（Artificial Societies Benchmark, 2026）。
  • 现有模拟停在固定脚本。NPC 在 A→B→C 里循环，最多在设计好的选项里挑一个，个体差异没有机会出现。
  • 社会能力没有规则，也没有判定器。它无法像围棋那样靠自博弈变强。

2框架

认知基因：一个接口契约，包含构念、参数、表达方式（prompt 模板或 steering vector）、测定任务和组合规则。
状态：此刻的人，包括精力、社交需求、情绪和时间压力。同一个人赶时间和闲逛时，行为不同。
脚本：文化共享的情境，比如点餐、上课、闲聊。在 RL 里，它就是 option。
仲裁：线索经过基因组和状态的评估，新目标与当前脚本竞争。个体差异主要出现在选择点和脚本断裂的时刻。
L0 循环固定日程 A→B→C→A
L1 选择在设计好的选项里挑
L2 遭遇世界弹出新状态：断裂、机会
L3 开放agent 自己生成选项，经检验器准入

3方法：四个模块

模块类型做什么产出
M1 认知基因库ML从行为实验数据（Psych-101、choices13k）中提取 4–6 个基因。每个基因用两种方式表达：prompt 模板，以及激活空间的 steering vector。用测定任务校准参数，并检验它们是否可辨识、可控、特异、可组合。基因库 v0，剂量–反应曲线
M2 选择点保真度ML在选择点上预测群体层面的两件事：人们会考虑哪些选项，最后选哪个。另外训练一个选项准入检验器，过滤 L3 自生成选项中不合理的部分。群体级保真度指标，准入检验器
M3 基因调度策略RL冻结 LLM，每一步由一个小型策略网络输出各基因的表达强度。奖励是群体级保真度：方差、相关结构和处理效应。模拟轨迹会与人类记录分叉，奖励无法求导，所以用 RL。调度策略，可读的调度轨迹
M4 世界生成器RL学出一个"地下城主"，生成 脚本 × 扰动（断裂或机会）× NPC 基因组。这是一个双层优化问题，外层目标是训练出的 agent 在真实评测（SOTOPIA 等）上的表现。群体分歧和 regret 作为便宜的代理信号。生成器，自动课程

4实验与评估

H1同一个小镇分别在 L0 到 L3 上运行。L0–L1 会复现"过于一致"的问题；L2–L3 加上基因组能修复它，而且不会滑向虚构。 H2RL 调度在群体保真度上优于固定基因组，也优于纯 prompt 人设。 H3在学出的世界里训练的 agent，在未见过的评测上优于手写场景、随机基因组和普通 UED。
  • 数据：Psych-101 和 choices13k 用于基因测定；Artificial Societies Benchmark 的公开测试用于群体保真度，可以与它报告的 9 个模型直接比较；SOTOPIA 用于社会能力评测。
  • 基线：人口统计人设 prompt、我们 CHI 2026 的模板方法、在人类数据上直接微调。
  • 风险与对策：LLM 可能记住了经典实验，所以使用改写和扰动过的版本。生成器可能过拟合评测集，所以把评测集拆成指导集和报告集。

两门课如何分工

ML 课M1 认知基因库 + M2 选择点保真度。回答"人是什么、像不像"。
RL 课M3 基因调度 + M4 世界生成器。回答"此刻怎么做、世界出什么题"。M4 是延伸目标。
合并两门课共同产出一篇论文，目标是 ICML poster 水平。

交付物

  • 一篇论文，含消融实验：自由度 L0–L3、基因表达方式（prompt vs steering）。
  • 交互式论文，也就是小镇 demo。它同时用于课程展示和融资演示。
  • 开源的基因库 v0 和评测脚本。

时间线

  1. 第 1–3 周选定基因，搭建测定任务，提取 steering vector
  2. 第 4–6 周小镇引擎支持 L0–L3，实现选择点和准入检验器
  3. 第 7–10 周训练 RL 调度策略和世界生成器，跑基线
  4. 第 11–13 周完整实验，写论文，定稿 demo

按 13 周学期估算，之后按两门课的实际截止日期调整。

对公司的意义

两个市场，一套引擎。

  • 决策模拟（市场研究、公共沟通）：卖的是群体保真度。
  • 社会能力训练环境（面向做 agent 的团队）：卖的是学出来的世界。

基因库和不断生长的脚本图都会持续积累，这是竞品只做"合成用户"所没有的资产。

交互式 demo SocietaBox Town 可以切换自由度 L0–L3，编辑居民的基因组，并查看世界生成器、基因调度和群体保真度三个面板。面板里的数值为示意，尚未用真实数据训练。
