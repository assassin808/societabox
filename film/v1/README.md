# YAX film v1: calibration (32.2 s)

A cognitive-genome film grounded in the YAX deck (v4) and the CoBRA paper (CHI 2026 Best Paper).

1. A description is not enough: a cognitive genome is a set of dials.
2. Pick a trait (following the crowd) and set a target: 2.6 on a 0–4 scale.
3. Measure it in classic human studies (Asch's line test, 1951; hotel towel study, 2008). The agent's A–E answers are weighted 4 to 0 into a Cognitive Bias Index score (1.9 here).
4. Adjust through the prompt (input), inner state (activations) or weights (parameters) until the level holds: set → measure → adjust.
5. Uncalibrated models A, B and C all converge on 2.6.
6. Anything measured in humans (biases, personality, emotion, social behaviour, decisions, values) can be set in an agent.
7. YAX, "calibrating AI to behave like humans", with SocietaGene and CoBRA · CHI 2026 Best Paper.

The numbers on screen (2.6, 1.9, the answer bars) are illustrative. They are not CoBRA results.

Files: `YAX_film_v1_calibration.mp4`, `yax_film_v1_player.html` (published at https://claude.ai/artifact/Qgdhdzyt2pnpjsJ4jCTr5C), `yax_film_v1.srt`, and sources in `src/`. The pipeline is the same as v0 (Kokoro narration, synthesized score, canvas renderer).
